# Calculadora de IMC

Projeto em Python que calcula o Índice de Massa Corporal (IMC) com base no peso e na altura informados pelo usuário.

## Funcionalidades

- Calcula o IMC usando a fórmula `peso / altura²`.
- Verifica se o peso e a altura estão dentro dos limites definidos no programa.
- Classifica o resultado em baixo peso, peso adequado, sobrepeso ou obesidade.
- Exibe um menu para fazer novos cálculos ou encerrar o programa.
- Trata entradas que não sejam numéricas.

## Requisitos

- Python 3 instalado.
